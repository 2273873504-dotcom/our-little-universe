# 给我们的小小宇宙

一个无需安装依赖的互动式恋爱小站。用浏览器直接打开 `index.html` 即可体验。顶栏和首页房间卡片可以切换到照片墙、故事簿、倒数日、游乐场、吵架存档、两地时间、心情日历和秘密信箱等独立界面。背景里的橘猫贴纸会轻轻浮动。

## 个性化

- 点右上角「设置」填写你们的昵称、她的生日和你们的纪念日。
- 照片墙里可以点照片放大查看，也可以添加更多照片；添加的照片保存在当前浏览器设备中。
- 首页背景和主视觉已加入 `assets/` 里的五张照片；如需替换，保持文件名即可。
- 在「故事簿」填写日期、标题和回忆，建立自己的时间线。
- 「约会游乐场」里有情侣问答、收集爱心和随机聊天题卡。
- 首页顶端直接显示南京与普利茅斯时间，首页也能直接操作心情月历。
- 默契游戏每天从题库抽出一组新题；也可以点「换一套」。玩法是先选答案、传手机给对方猜，再揭晓两人是否想到一起。
- 「吵架存档」可记录时间、事情和感受，并标注之后是否已经和好。
- 「两地时间」显示南京与英国普利茅斯的当地时间；天气通过 Open-Meteo 获取，需要网络连接。
- 「心情日历」可以给日期记心情，并手动标记经期日期；两类记录都只存在本地浏览器。
- 第一次进入「秘密信箱」时设置四位数字暗号，再编辑信笺。

## 数据说明

昵称、日期、信笺、爱心数、故事簿、吵架记录、心情和经期日期都保存在当前浏览器的本地存储；新上传的照片保存在当前浏览器的 IndexedDB。首页装饰照片和初始相册照片作为网站本地资源保存在 `assets/`。这些私人内容不会上传。两地天气查询只向公开天气服务请求南京和普利茅斯的天气，不发送心情、经期或故事记录。换设备或清除浏览器数据后，本地保存的内容不会自动同步。秘密信箱的暗号只是轻量入口，不是加密保护，请勿放入高度敏感的信息。
